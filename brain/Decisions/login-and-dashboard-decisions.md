# Login split photo and all-branch dashboard services
Date: 2026-11-25
Status: approved by owner

Decisions:
- Login uses a split layout on desktop (cover photo left, form right) and form only on mobile.
- The member dashboard shows upcoming services from ALL branches, with the member's own branch first and each service labelled by branch.

Why: members can join events at other branches, and the owner wants one place to see the full schedule. The own branch comes first so the most relevant services are seen first.
