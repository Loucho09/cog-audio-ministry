# Admins equal per branch
Date: 2026-11-25
Owner rule.

- Branch-head and branch-admin have the same powers, but only for their own branch.
- Only the super-admin works across all branches.
- Role assignment and creating branches stay super-admin only (unchanged).

Consequence: branch-admins can now create, edit and delete services (own branch).
